# APEX FORMULA — Monza

기존 Phase 1 프로젝트를 확장한 로컬 3D 아케이드 포뮬러 레이싱 게임입니다.

## 실행

```sh
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고 **그리드 진입**을 누르세요.

## 조작

- W / ↑: 가속, S / ↓: 브레이크
- A / ←: 왼쪽, D / →: 오른쪽
- Shift: ERS 부스트 (사용 후 자동 충전)
- C: 추적 / 운전석 카메라
- G: 권장 주행 라인 표시
- R: 현재 구간 트랙 중앙으로 복귀 (랩 기록 유지)
- Esc: 일시정지 / 재개
- Enter: 출발 / 완주 후 다시 도전

## 레이스

5대의 AI와 3랩 레이스를 진행합니다. 순위, 현재·직전·최고 랩, 미니맵, 기어, 페달 입력과 부스트 잔량을 표시합니다. 최고 랩은 브라우저에 저장됩니다. 트랙 밖에서는 감속하며, 외곽 경계 및 차량 간 접촉에는 간단한 아케이드 방식의 반응을 적용합니다. 공식 F1 라이선스 콘텐츠나 정밀 물리 시뮬레이터는 포함하지 않습니다.

## 콕핏 및 3D 주행 가이드

기본 시점은 낮은 운전석입니다. 앞바퀴, 헤일로와 실시간 계기판을 구현하고 조명탑, 펜스, 도심 스카이라인을 추가했습니다. 참고 영상의 구도를 바탕으로 만든 자체 간소화 그래픽이며 상용 F1 게임과 같은 수준의 자산·반사·차량 모델은 아닙니다.

주행 가이드는 코너 진입 때 나타나는 수직 리본과 부유 표식으로 렌더링합니다. 녹색은 가속, 노란색은 속도 유지, 빨간색은 감속이며 색의 강도가 연속적으로 변합니다. 주행 가이드 화살표는 G 키로 켜고 끌 수 있습니다. 오른쪽에는 전체 서킷 미니맵을 표시합니다.

LinePlanner는 트랙을 약 4 m 간격으로 샘플링하고 차량 폭 여유를 남깁니다. 점의 간격이 달라져도 올바르게 비교할 수 있도록 실제 곡률의 제곱을 거리로 적분해 경로를 평가하며, 넓은 구간부터 0.1 m 단위의 세밀한 이동까지 탐색해 코너 진입·정점·탈출을 연결합니다. 곡률 기반 코너 속도와 앞뒤 가속·제동 제한을 순환 전파해 제동 시점을 미리 반영합니다. 현재 아케이드 물리를 위한 근사 권장 경로이며 전역 최단 랩타임을 보장하지 않습니다. 노면, 타이어, 동적 추월 상황까지 해석하는 정밀 시뮬레이션은 아닙니다.

## 주행 시스템 v2

- ESC 또는 창 비활성화 시 레이스가 멈추고 메뉴가 열립니다. 계속하기, 트랙 복귀, 시점 변경, 재시작과 운전석 높이(1.5–2.8 m)를 지원합니다.
- 물리는 120 Hz 고정 시간 간격으로 계산합니다. 커스텀 평면 차량 모델에서 앞뒤 타이어 슬립, 횡방향 관성, 요 회전 관성, 마찰 원, 제동 하중 이동, 다운포스, 노면별 접지와 항력을 계산합니다. 차체 피치·롤은 시각적 서스펜션 반응입니다. 6자유도 강체나 손상 시뮬레이터는 아닙니다.
- 차량 간 접촉에는 캡슐 형태의 충돌 판정, 위치 분리와 운동량 교환을 사용합니다. 외벽은 진입 방향 속도 성분을 반사합니다.
- 권장 속도는 차량과 같은 그립·제동 함수를 사용합니다. 멀리 있는 코너의 낮은 속도를 현재 속도와 바로 비교하지 않고, 남은 거리와 반응 여유를 반영합니다. 제동 안내에는 히스테리시스를 적용해 경계값에서 깜박임을 줄였습니다.
- AI는 공통 차량 물리를 사용하면서 각기 다른 페이스, 반응 주기, 공격성, 주행선 편향을 가집니다. 전방 차량과 통로를 확인해 추월 위치를 선택하고 막히면 감속합니다. 트랙 밖에서 정체가 지속되면 해당 지점으로 복귀하며 주행 거리를 추가하지 않습니다.
- 사진을 참고해 은색 노즈, 다단 프런트 윙, 사이드포드, 서스펜션 암, 타이어 측면과 곡면 숄더, 운전석 헤일로와 장갑을 자체 메시로 제작했습니다. 기본 눈높이는 1.8 m이며 메뉴에서 조절할 수 있습니다.

## Monza GP layout

현재 기본 트랙은 이탈리아 몬차 GP 레이아웃입니다. 공개 지리 좌표를 지역 미터 좌표로 투영하고 길이를 공식 5,793 m에 맞췄습니다. 첫 코너까지 약 1 km의 직선 가속 구간을 두고, 레티필로·쿠르바 그란데·로지아·레즈모·아스카리·파라볼리카를 유지합니다. 긴 직선은 점을 촘촘히 보간한 뒤 곡선을 생성해 불필요한 휨을 방지했습니다.

입문 편의를 위해 노면 폭과 주변 환경은 게임용으로 구성했고 고도는 평면으로 단순화했습니다. 실측/레이저 스캔 모델은 아닙니다. 조명탑을 유지하고 화면은 해질녘 광원으로 표현합니다. 몬차가 모든 사용자에게 가장 쉽다는 뜻은 아니며, 긴 직선에서 가속·제동을 연습하기 좋다는 기준으로 선택했습니다. 첫 시케인에서는 충분히 감속해야 합니다.

- Official circuit guide: https://www.formula1.com/en/information/italy-autodromo-nazionalemonza.FiJN1jnQlRLeHqOxIt13m
- Centerline data and license: see THIRD_PARTY_NOTICES.md
- 다음 코너 이름·거리, 150/100/50 m 제동 표지판, 자동 축척 미니맵을 지원합니다.
- 권장 경로를 약 4 m 간격으로 계산하고, 진행도는 약 2 m 간격의 선분 투영으로 추적합니다.
- 최고 랩 기록은 이전 가상 트랙과 분리해 저장합니다.

### 주행선 회귀 검증

동일한 자동 조향·속도 제어기로 실제 차량 물리를 적용해 몬차 1랩을 검증합니다.
곡률 기반 경로 변경 전 139.9초에서 변경 후 약 120.3초로 개선되었으며, 검증 주행에서 트랙 이탈은 없었습니다.
이는 충돌 없는 자동 제어 테스트 결과로, 키보드 플레이에서 같은 기록이나 미끄러짐 없는 주행을 보장하는 수치는 아닙니다.
샘플 사이 경로의 도로 안쪽 여유, 진행 방향, 제동 속도 제한, AI 주행도 함께 검사합니다.


## 플레이어에 맞춰 달리는 AI

라이벌은 플레이어와의 누적 주행 거리 차이에 따라 페이스를 자동 조절합니다.
플레이어가 크게 뒤처지면 앞선 라이벌이 속도를 낮추고, 플레이어가 앞서면 뒤처진 라이벌이 페이스와 직선 부스트 사용을 높입니다.
45 m 이내의 접전에서는 각 차량의 기본 성향을 유지합니다. 출발 직후에는 보정을 유예하고, 이후 몇 초에 걸쳐 부드럽게 적용합니다.
격차 보정은 목표 속도와 운전 입력을 조절합니다. 86초 페이스를 위해 AI에는 아래의 고정 성능 보정도 적용합니다. 랩 차이도 누적 거리로 판단하고, 레이스 재시작 시 보정을 초기화합니다.


### 라이벌 주행 제어 개선

AI는 사람용 조기 제동 안내 대신 경로의 속도 프로파일을 짧은 반응 거리로 추적합니다.
다가오는 가감속과 공기저항에 필요한 입력을 미리 계산해 목표 속도 근처에서 불필요하게 가속을 놓지 않습니다.
직선에서는 배터리 잔량에 따라 부스트를 사용하며, 기본 페이스와 반응 속도도 높였습니다.
추월은 양쪽 통로의 도로 여유와 주변 차량을 확인하고, 나란히 달리는 차량이 있으면 차선을 유지합니다.
급한 코너에서는 무리한 추월을 시도하지 않습니다. 앞서 있을 때의 최대 목표 페이스 감소는 30%로 제한하고,
뒤처지면 더 적극적으로 추격합니다. 공통 최고속도 제한과 실제 물리 적분은 유지합니다.

동일한 단독 주행 벤치마크에서 첫 랩이 기존 120.3초에서 약 107.0초로 개선되었고 트랙 이탈은 없었습니다.
느린 차량의 직선 추월과 빠른 플레이어를 추격하는 5대의 다중 랩 주행도 회귀 테스트로 검증합니다.


## 중앙 후방 미러 및 강화된 기본 페이스

화면 중앙 상단의 백미러는 실제 후방 장면을 별도 카메라로 렌더링하며, 거울처럼 좌우를 반사합니다.
운전석·추적 시점 모두 표시되고 화면 크기에 맞춰 조절됩니다. 추가 렌더링의 해상도는 최대 640×180으로 제한합니다.
미러에서 본인 차량이 시야를 가리지 않도록 해당 렌더링에서만 숨기고, 주 화면의 렌더링 상태를 복구합니다.

라이벌의 기본 목표 페이스와 반응 속도를 다시 높이고, 별도의 코너 탈출 가속 프로파일을 사용합니다.
접지 한계에 가까울 때는 가속 여유를 줄여 코너링에 힘을 남깁니다. 플레이어와의 격차에 따른 페이스 보정은 유지합니다.
동일한 단독 주행에서 첫 랩 약 100.0초, 다음 랩 약 96.8초를 기록했으며 트랙 이탈은 없었습니다
(이전 릴리스: 첫 랩 약 107.0초, 다음 랩 약 103.9초). 이는 자동 주행 벤치마크 결과입니다.


## 1분 26초 기준 AI 보정

플레이어의 베스트 86초와 첫 랩 90초 미만을 기준으로 선두 라이벌을 조정했습니다.
중립적인 격차 보정 상태에서 3랩을 실제 물리로 연속 주행한 결과는 **88.06 / 86.28 / 86.25초**이며,
이 단독 주행에서는 트랙 이탈이 없었습니다. 다른 차량과 함께 달릴 때는 접촉·추월·격차 보정에 따라 기록이 달라집니다.

이 페이스에는 **AI 전용의 고정 가속·접지 보정**이 포함됩니다. AI의 엔진 출력 계수는 1.35,
타이어 접지 및 제동 계수는 1.40입니다. 차량 성능 입력은 1.0~1.5로 제한하며 플레이어는 두 값 모두 1.0을 사용합니다.
플레이어 차량과 권장 속도 안내는 기존 설정을 유지하고, AI도 동일한 물리 적분과 하드 최고속도(87 m/s, 부스트 시 94 m/s)를 따릅니다.
순간적인 위치 이동이나 시간 배속으로 기록을 맞추지 않습니다.

출발 그리드를 간격 있게 배치하고, 나란히 달리는 차량을 가로지르는 합류를 막았습니다.
추월 중에는 해당 통로의 코너 곡률과 제동 거리를 따로 확인합니다.
테스트는 3랩 목표 기록, 플레이어 기본 물리의 동일성, AI 성능 상한, 격차 보정 및 합류 판단을 검증합니다.


## 그래픽 1차 개선: 재질·조명·노면

차량 도장은 클리어코트와 환경 반사를 사용하고, 카본·고무에는 자체 생성한 컬러·높이·거칠기 맵을 적용합니다.
차체와 노즈·사이드포드는 곡면 단면으로 구성했으며 헤일로, 휠 스포크, 허브, 디퓨저와 후미등을 보강했습니다.
아스팔트·잔디 질감과 코너의 고무 자국, 해질녘 HDR 환경 조명 및 차량 그림자를 추가했습니다.
고품질 실차 스캔 모델을 도입한 단계는 아니며, 모든 새 재질은 로컬에서 생성되어 외부 이미지 다운로드가 필요하지 않습니다.

성능을 위해 정적 차체를 재질별로 병합하고, 그림자 계산 범위는 플레이어 주변으로 한정합니다.
그림자 맵은 큰 화면 2048 / 작은 화면 1024이며 백미러는 주 화면의 그림자 결과를 재사용합니다.
오른쪽 중앙의 속도 가이드 패널은 제거하고 미니맵을 그 자리로 이동했습니다. 노면 가이드와 현재 속도 계기판은 유지합니다.
PC·작은 화면과 운전석·추적 시점의 표시를 브라우저에서 확인했습니다. 그래픽 변경 후 AI의 3랩 검증 기록은
88.06 / 86.28 / 86.25초로 동일하며, 주행 물리·AI 보정은 변경하지 않았습니다.


## 코너 진입 전용 유도선

긴 직선에서는 숨기고, 현재 속도와 제동거리에 맞춰 코너 진입 전에 표시합니다.
시케인은 연결된 동작으로 취급하며 최적화된 경로의 진입·정점·탈출까지 안내한 뒤 사라집니다.
