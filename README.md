# APEX FORMULA — Monza

기존 Phase 1 프로젝트를 확장한 로컬 3D 아케이드 포뮬러 레이싱 게임입니다.

## 실행

Node.js 버전은 `.nvmrc`의 24.19.0을 사용합니다. CI와 로컬의 장시간 물리 재현 결과를 맞추기 위해 동일한 런타임을 사용합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고 **그리드 진입**을 누르세요.

## 조작

- W / ↑: 가속, S / ↓: 브레이크
- A / ←: 왼쪽, D / →: 오른쪽
- Shift: ERS 부스트 (사용 후 자동 충전)
- C: 추적 / 운전석 카메라
- G: 권장 주행 라인 표시
- R: 현재 구간 트랙 중앙으로 복귀 (랩 기록 유지)
- Esc: 일시정지 / 재개
- Enter: 출발 / 완주 후 다시 도전

## 레이스

5대의 AI와 3랩 레이스를 진행합니다. 순위, 현재·직전·최고 랩, 미니맵, 기어, 페달 입력과 부스트 잔량을 표시합니다. 최고 랩은 브라우저에 저장됩니다. 트랙 밖에서는 감속하며, 외곽 경계 및 차량 간 접촉에는 간단한 아케이드 방식의 반응을 적용합니다. 공식 F1 라이선스 콘텐츠나 정밀 물리 시뮬레이터는 포함하지 않습니다.

## 콕핏 및 3D 주행 가이드

기본 시점은 낮은 운전석입니다. 앞바퀴, 헤일로와 실시간 계기판을 구현하고 조명탑, 펜스, 도심 스카이라인을 추가했습니다. 참고 영상의 구도를 바탕으로 만든 자체 간소화 그래픽이며 상용 F1 게임과 같은 수준의 자산·반사·차량 모델은 아닙니다.

주행 가이드는 코너 진입 때 나타나는 수직 리본과 부유 표식으로 렌더링합니다. 녹색은 가속, 노란색은 속도 유지, 빨간색은 감속이며 색의 강도가 연속적으로 변합니다. 주행 가이드 화살표는 G 키로 켜고 끌 수 있습니다. 오른쪽에는 전체 서킷 미니맵을 표시합니다.

LinePlanner는 트랙을 약 4 m 간격으로 샘플링하고 차량 폭 여유를 남깁니다. 점의 간격이 달라져도 올바르게 비교할 수 있도록 곡률의 제곱과 거리/권장 속도 기반의 통과 시간 비용을 함께 평가하고, 안쪽 정점 통과 조건을 적용하며, 넓은 구간부터 0.1 m 단위의 세밀한 이동까지 탐색해 코너 진입·정점·탈출을 연결합니다. 곡률 기반 코너 속도와 앞뒤 가속·제동 제한을 순환 전파해 제동 시점을 미리 반영합니다. 현재 아케이드 물리를 위한 근사 권장 경로이며 전역 최단 랩타임을 보장하지 않습니다. 노면, 타이어, 동적 추월 상황까지 해석하는 정밀 시뮬레이션은 아닙니다.

## 주행 시스템 v2

- ESC 또는 창 비활성화 시 레이스가 멈추고 메뉴가 열립니다. 계속하기, 트랙 복귀, 시점 변경, 재시작과 운전석 높이(1.5–2.8 m)를 지원합니다.
- 물리는 120 Hz 고정 시간 간격으로 계산합니다. 커스텀 평면 차량 모델에서 앞뒤 타이어 슬립, 횡방향 관성, 요 회전 관성, 마찰 원, 제동 하중 이동, 다운포스, 노면별 접지와 항력을 계산합니다. 차체 피치·롤은 시각적 서스펜션 반응입니다. 6자유도 강체나 손상 시뮬레이터는 아닙니다.
- 차량 간 접촉에는 캡슐 형태의 충돌 판정, 위치 분리와 운동량 교환을 사용합니다. 외벽은 진입 방향 속도 성분을 반사합니다.
- 권장 속도는 차량과 같은 그립·제동 함수를 사용합니다. 멀리 있는 코너의 낮은 속도를 현재 속도와 바로 비교하지 않고, 남은 거리와 반응 여유를 반영합니다. 제동 안내에는 히스테리시스를 적용해 경계값에서 깜박임을 줄였습니다.
- AI는 공통 차량 물리를 사용하면서 각기 다른 페이스, 반응 주기, 공격성, 주행선 편향을 가집니다. 전방 차량과 통로를 확인해 추월 위치를 선택하고 막히면 감속합니다. 트랙 밖에서 정체가 지속되면 해당 지점으로 복귀하며 주행 거리를 추가하지 않습니다.
- 사진을 참고해 은색 노즈, 다단 프런트 윙, 사이드포드, 서스펜션 암, 타이어 측면과 곡면 숄더, 운전석 헤일로와 장갑을 자체 메시로 제작했습니다. 기본 눈높이는 1.8 m이며 메뉴에서 조절할 수 있습니다.

## Monza GP layout

현재 기본 트랙은 이탈리아 몬차 GP 레이아웃입니다. 공개 지리 좌표를 지역 미터 좌표로 투영하고 길이를 공식 5,793 m에 맞췄습니다. 첫 코너까지 약 1 km의 직선 가속 구간을 두고, 레티필로·쿠르바 그란데·로지아·레즈모·아스카리·파라볼리카를 유지합니다. 긴 직선은 점을 촘촘히 보간한 뒤 곡선을 생성해 불필요한 휨을 방지했습니다.

입문 편의를 위해 노면 폭과 주변 환경은 게임용으로 구성했고 고도는 평면으로 단순화했습니다. 실측/레이저 스캔 모델은 아닙니다. 조명탑을 유지하고 화면은 해질녘 광원으로 표현합니다. 몬차가 모든 사용자에게 가장 쉽다는 뜻은 아니며, 긴 직선에서 가속·제동을 연습하기 좋다는 기준으로 선택했습니다. 첫 시케인에서는 충분히 감속해야 합니다.

- Official circuit guide: https://www.formula1.com/en/information/italy-autodromo-nazionalemonza.FiJN1jnQlRLeHqOxIt13m
- Centerline data and license: see THIRD_PARTY_NOTICES.md
- 다음 코너 이름·거리, 150/100/50 m 제동 표지판, 자동 축척 미니맵을 지원합니다.
- 권장 경로를 약 4 m 간격으로 계산하고, 진행도는 약 2 m 간격의 선분 투영으로 추적합니다.
- 최고 랩 기록은 이전 가상 트랙과 분리해 저장합니다.

### 주행선 회귀 검증

동일한 자동 조향·속도 제어기로 실제 차량 물리를 적용해 몬차 1랩을 검증합니다.
곡률 기반 경로 변경 전 139.9초에서 변경 후 약 120.3초로 개선되었으며, 검증 주행에서 트랙 이탈은 없었습니다.
이는 충돌 없는 자동 제어 테스트 결과로, 키보드 플레이에서 같은 기록이나 미끄러짐 없는 주행을 보장하는 수치는 아닙니다.
샘플 사이 경로의 도로 안쪽 여유, 진행 방향, 제동 속도 제한, AI 주행도 함께 검사합니다.


## 플레이어에 맞춰 달리는 AI

라이벌은 플레이어의 순위와 누적 주행 거리 차이에 따라 직선 최고속도와 가속 여력을 조절합니다.
플레이어가 크게 뒤처지면 앞선 라이벌이 속도를 낮추고, 플레이어가 앞서면 뒤처진 라이벌이 페이스와 직선 부스트 사용을 높입니다.
출발 직후에는 보정을 유예하고, 이후 몇 초에 걸쳐 부드럽게 적용합니다. 근접 상황에서는 추월 통로와 앞뒤 차량의 여유를 확인합니다.
순위 보정은 직선 속도 상한과 추격 출력을 조절하며, 앞선 차량의 코너 페이스를 크게 낮추지 않습니다. 86초 페이스를 위해 AI에는 아래의 고정 성능 보정도 적용합니다. 랩 차이도 누적 거리로 판단하고, 레이스 재시작 시 보정을 초기화합니다.


### 라이벌 주행 제어 개선

AI는 사람용 조기 제동 안내 대신 경로의 속도 프로파일을 짧은 반응 거리로 추적합니다.
다가오는 가감속과 공기저항에 필요한 입력을 미리 계산해 목표 속도 근처에서 불필요하게 가속을 놓지 않습니다.
직선에서는 배터리 잔량에 따라 부스트를 사용하며, 기본 페이스와 반응 속도도 높였습니다.
추월은 양쪽 통로의 도로 여유와 주변 차량을 확인하고, 나란히 달리는 차량이 있으면 차선을 유지합니다.
급한 코너에서는 무리한 추월을 시도하지 않습니다. 앞선 차량은 최고속도 상한을 약 1.2~2% 낮추고 ERS를 충전하며,
뒤처지면 더 적극적으로 추격합니다. 플레이어의 기본 속도 제한은 유지하며 뒤처진 AI의 속도 상한만 확장합니다. 속도 변경은 실제 물리 적분으로 반영합니다.

동일한 단독 주행 벤치마크에서 첫 랩이 기존 120.3초에서 약 107.0초로 개선되었고 트랙 이탈은 없었습니다.
느린 차량의 직선 추월과 빠른 플레이어를 추격하는 5대의 다중 랩 주행도 회귀 테스트로 검증합니다.


## 중앙 후방 미러 및 강화된 기본 페이스

화면 중앙 상단의 백미러는 실제 후방 장면을 별도 카메라로 렌더링하며, 거울처럼 좌우를 반사합니다.
운전석·추적 시점 모두 표시되고 화면 크기에 맞춰 조절됩니다. 추가 렌더링의 해상도는 최대 640×180으로 제한합니다.
미러에서 본인 차량이 시야를 가리지 않도록 해당 렌더링에서만 숨기고, 주 화면의 렌더링 상태를 복구합니다.

라이벌의 기본 목표 페이스와 반응 속도를 다시 높이고, 별도의 코너 탈출 가속 프로파일을 사용합니다.
접지 한계에 가까울 때는 가속 여유를 줄여 코너링에 힘을 남깁니다. 플레이어와의 격차에 따른 페이스 보정은 유지합니다.
동일한 단독 주행에서 첫 랩 약 100.0초, 다음 랩 약 96.8초를 기록했으며 트랙 이탈은 없었습니다
(이전 릴리스: 첫 랩 약 107.0초, 다음 랩 약 103.9초). 이는 해당 버전의 자동 주행 벤치마크 결과입니다. 현재 순위별 보정의 동작은 아래 항목을 참고하세요.


## 1분 26초 기준 AI 보정

플레이어의 베스트 86초와 첫 랩 90초 미만을 기준으로 선두 라이벌을 조정했습니다.
순위별 보정을 제외한 기본 주행 회귀 테스트에서 3랩 결과는 **87.21 / 85.74 / 85.66초**이며,
이 단독 주행에서는 트랙 이탈이 없었습니다. 다른 차량과 함께 달릴 때는 접촉·추월·격차 보정에 따라 기록이 달라집니다.

이 페이스에는 **AI 전용의 고정 가속·접지 보정**이 포함됩니다. AI의 엔진 출력 계수는 1.35,
타이어 접지 및 제동 계수는 1.40입니다. 차량 성능 입력은 1.0~1.5로 제한하며 플레이어는 두 값 모두 1.0을 사용합니다.
플레이어 차량과 권장 속도 안내는 기존 설정을 유지하고, 기본 속도 한도는 87 m/s, 부스트 시 94 m/s입니다. 플레이어는 이를 유지하고 AI는 아래 순위 보정에 따라 추가 상한을 사용합니다.
순간적인 위치 이동이나 시간 배속으로 기록을 맞추지 않습니다.

출발 그리드를 간격 있게 배치하고, 나란히 달리는 차량을 가로지르는 합류를 막았습니다.
추월 중에는 해당 통로의 코너 곡률과 제동 거리를 따로 확인합니다.
테스트는 3랩 목표 기록, 플레이어 기본 물리의 동일성, AI 성능 상한, 격차 보정 및 합류 판단을 검증합니다.


## 그래픽 1차 개선: 재질·조명·노면

차량 도장은 클리어코트와 환경 반사를 사용하고, 카본·고무에는 자체 생성한 컬러·높이·거칠기 맵을 적용합니다.
차체와 노즈·사이드포드는 곡면 단면으로 구성했으며 헤일로, 휠 스포크, 허브, 디퓨저와 후미등을 보강했습니다.
아스팔트·잔디 질감과 코너의 고무 자국, 해질녘 HDR 환경 조명 및 차량 그림자를 추가했습니다.
고품질 실차 스캔 모델을 도입한 단계는 아니며, 모든 새 재질은 로컬에서 생성되어 외부 이미지 다운로드가 필요하지 않습니다.

성능을 위해 정적 차체를 재질별로 병합하고, 그림자 계산 범위는 플레이어 주변으로 한정합니다.
그림자 맵은 큰 화면 2048 / 작은 화면 1024이며 백미러는 주 화면의 그림자 결과를 재사용합니다.
오른쪽 중앙의 속도 가이드 패널은 제거하고 미니맵을 그 자리로 이동했습니다. 노면 가이드와 운전대의 실제 계기판은 유지합니다. 별도 화면용 속도계 패널은 제거했습니다.
PC·작은 화면과 운전석·추적 시점의 표시를 브라우저에서 확인했습니다. 그래픽 변경 후 AI의 3랩 검증 기록은
88.06 / 86.28 / 86.25초로 유지되었습니다. 현재 AI의 순위별 보정은 아래 항목과 별도 검증을 사용합니다.


## 코너 진입 전용 유도선

긴 직선에서는 숨기고, 현재 속도와 제동거리에 맞춰 코너 진입 전에 표시합니다.
시케인은 연결된 동작으로 취급하며 최적화된 경로의 진입·정점·탈출까지 안내한 뒤 사라집니다.
한 번 진입 안내가 시작되면 감속 중 표시 조건이 바뀌어도 탈출까지 유지합니다. G 키로 전체 표시를 끌 수 있습니다.

유도선은 노면에 그리지 않고 지면에서 0.25~0.73 m 높이에 수직으로 세운 반투명 리본입니다.
정면으로 볼 때 리본이 가늘어지는 경우에도 경로를 읽을 수 있도록 수직 방향 표식을 함께 배치합니다.
현재 차속과 경로상의 권장 속도 차이, 필요한 가감속을 빨강·주황·노랑·초록의 연속 색상으로 표시합니다.
가까운 부분은 실제 현재 속도를 사용하고, 먼 부분은 제동·가속 한도 안에서 예상 도달 속도를 계산하여
진입 때의 높은 속도 때문에 탈출 구간까지 무조건 빨강이 되는 현상을 피합니다. 리본 가장자리와 끝은 투명하게 페이드됩니다.
플레이어·AI 물리와 경로 최적화 계산은 변경하지 않았습니다.


## 순위에 따른 최고속도 및 선두 경쟁

- 플레이어보다 뒤의 AI는 격차가 커질수록 직선 최고속도와 추격 출력을 높입니다. 설정상 상한은 부스트 110 m/s, 일반 주행 약 101.8 m/s이며 실제 도달 속도는 출력·항력·배터리에 의해 제한됩니다. 직선 추격 출력에는 최대 1.35배의 추가 계수를 속도에 따라 점진적으로 적용합니다.
- 플레이어보다 앞의 AI는 기존 최고속도 상한에서 약 1.2~2%만 낮추고 ERS를 비축합니다. 기존의 큰 코너 페이스 감소는 사용하지 않습니다.
- 플레이어가 선두일 때 2·3등은 약 14초 간격으로 주공격 역할을 교대합니다. 상위 3위 경쟁 중 플레이어가 추월당하면 새로 뒤처진 차량이 추격 역할을 이어받습니다.
- 추월이 끝나 순위가 바뀌면 속도 상한과 출력 보정이 서서히 바뀝니다. 상한이 낮아져도 현재 속도를 강제로 잘라내지 않고 엔진 제어·항력·브레이크로 감속합니다.
- 추월 통로에서도 확장된 속도 상한을 사용합니다. 합류할 때는 옆 차량과 통로를 확인하며, 뒤에서 빠르게 접근하는 차량에는 더 넓은 여유를 둡니다.

같은 차량의 6초 직선 시험에서는 앞선 역할 약 306.9 km/h, 추격 역할 약 356.0 km/h의 최고속도를 확인했습니다.
86초 수준의 기준 드라이버와 두 AI로 구성한 250초 물리 테스트에서는
PLAYER → NOVA → PLAYER → NOVA → PLAYER의 선두 교환을 확인했습니다. 기준 드라이버는 테스트용 성능 보정을 사용하며 앱의 플레이어 차량 설정은 변경하지 않습니다.
순위 보정은 차량의 위치나 주행 거리를 강제로 옮기지 않습니다. 재시작 시 모든 보정과 라이벌의 ERS 잔량을 초기화합니다.


## 바깥쪽에 치우친 코너 라인 수정

일반적인 단일 코너는 바깥쪽 진입 → 안쪽 정점 → 바깥쪽 탈출을 사용합니다.
연속 코너에서는 다음 턴과 탈출 가속을 위해 각 정점의 위치를 함께 고려해야 합니다.
이전의 굽힘 최소화만으로는 큰 바깥 반지름을 계속 선택할 수 있어 레즈모·파라볼리카에서 외측 편향이 발생했습니다.

새 계산은 진행 방향의 부호와 누적 회전각으로 몬차의 11개 정점을 구분하고, 각 정점의 안쪽을 통과하도록 경로를 최적화합니다.
급한 시케인에는 더 작은 안쪽 이동량을 사용하고, 정점의 한 지점만 제한하여 안쪽 원호에 붙어 급하게 꺾이는 현상을 피합니다.
전체 경로의 굽힘과 예상 통과 시간을 함께 평가하고 차량 폭 여유를 유지합니다. 전역 최단 랩타임을 보장하는 해석기는 아닙니다.
검증은 11개 정점의 실제 안쪽 방향, 레즈모·파라볼리카의 진입/정점/탈출 위치, 시케인의 좌우 전환과 물리 주행을 검사합니다.
화면용 속도계·기어·ERS 패널은 제거했으며 운전대 계기판, 미니맵과 백미러는 유지합니다.


## 1단계: 키보드 조작감 개선 (검토용)

플레이어의 키보드 입력에는 속도에 따른 조향 증가율, 빠른 중립 복귀와 제한된 차체 안정화 보정을 적용합니다.
코너에서 과도한 조향을 줄이고, 제동과 조향을 함께 할 때 타이어의 횡방향 여유를 남기도록 제동력을 조절합니다.
따라서 코너 안에서는 직선보다 제동 거리가 길어질 수 있으며, 진입 전 감속은 여전히 필요합니다.
W와 S를 함께 누르면 브레이크를 우선하고 제동 중에는 ERS를 소모하지 않습니다.
앞바퀴는 실제 물리 조향각을 표시합니다. 기본 엔진 출력과 타이어 접지력은 그대로이며 AI 제어에는 키보드 보정을 적용하지 않습니다.

120 Hz 재현 시험에서 감속 후 풀조향의 최대 미끄러짐은 약 6.8° → 5.9°, 제동 중 풀조향은 25.4° → 5.4°로 감소했습니다.
직선 제동 거리, 선회 능력과 조향 해제 후 안정화도 검사합니다. 실제 조작감 확인 후 다음 단계로 진행합니다.


## 2단계: 레이싱 라인 검증 및 속도 안내 보완

1단계 조작감은 확정했으며 이 단계에서는 차량 물리를 변경하지 않습니다.
기존의 11개 안쪽 정점, 단일 코너의 바깥–안쪽–바깥 경로와 시케인의 좌우 전환을 다시 검사합니다.
플레이어의 키보드 보정이 적용된 물리 모델로도 테스트 제어기가 한 바퀴를 완주하며,
모든 정점에서 라인과의 위치 오차 2m 이내, 도로 이탈 0회를 검사합니다.
이는 테스트 제어기의 검증 결과이며 사람의 키 입력으로 항상 같은 결과가 난다는 보장은 아닙니다.

제동 안내와 색상 예측은 도로 중심선 대신 실제 유도선의 누적 거리를 사용합니다.
잔디에서는 횡방향 접지력까지 반영해 코너 권장 속도를 낮추고, 정지 거리만큼 미리 탐색합니다.
고정 240m 탐색과 300m 표시 제한 때문에 저접지 상황에서 안내가 늦어질 수 있던 문제를 보완했습니다.
길고 빠른 직선에서는 기존처럼 유도선을 숨기며, 코너 진입·탈출의 수직 유도선과 연속 색상 변화를 유지합니다.

감속 중 다운포스가 줄어드는 제동력 변화도 구간별로 계산하며, 안내 표시 시점과 속도 안내에 같은 정지 거리 계산을 사용합니다.


## 3단계: AI 근접 레이스 개선

추월 통로를 선택하면 1.5초 동안 같은 쪽을 우선하여, 앞차의 작은 움직임에 좌우 선택이 반복되는 현상을 줄입니다.
통로가 막히거나 도로 폭을 벗어나면 다른 쪽을 선택할 수 있습니다.
접근 속도와 제동 여유를 고려해 빠르게 닫히는 간격에는 먼저 감속하며,
추월 후 합류 시 빠르게 접근하는 뒤차까지 확인합니다.

공격적인 라이벌은 코너 약 200–260m 전 직선에서 한 번만 안쪽으로 방어합니다.
방어 유지 시간은 1.2초, 다음 방어까지 대기는 8초이며, 공격 차량이 나란히 붙으면 방어를 취소합니다.
추월 우선순위의 차량은 ERS 잔량 18 이상부터 공격할 수 있고, 일반 차량은 기존의 35 기준을 유지합니다.
앞차에 막혀 통로가 없을 때는 ERS를 아낍니다.
순위별 최고속도·출력 범위와 확정된 플레이어 조작감, 레이싱 라인은 유지합니다.

검증: AI의 실제 3랩 약 87.21 / 85.74 / 85.66초, 도로 이탈 0회.
250초 접전 시험에서는 AI의 2초 이상 선두 탈환과 테스트 드라이버의 재추월이 네 차례 발생했습니다.
테스트 드라이버는 기준 성능을 가진 자동 제어기이며 사람의 실제 경기 결과를 보장하지 않습니다.
추월 방향 유지·막힌 통로 회피·접근 속도에 따른 제동·방어 대기·나란히 주행 시 방어 취소·ERS 사용·재시작 초기화를 별도로 검사합니다.

## 4단계: 주행 사운드 · 충돌 피드백 · 출발 균형

Web Audio로 엔진 회전/부하음, 움직이는 차량의 제동음, 접지 한계와 횡미끄러짐에 따른 타이어 마찰음,
아스팔트/잔디 노면음을 합성합니다. 주변 AI 엔진음에는 거리 감쇠와 운전자 기준 좌우 패닝을 적용합니다.
실차 녹음 자산을 사용하지 않는 합성 사운드입니다. 첫 클릭 또는 키 입력으로 오디오를 활성화하며,
일시정지·창 비활성화·완주·재시작 때 페이드아웃합니다. M 키로 음소거하고 ESC 메뉴에서 음량을 조절합니다.
음량은 브라우저에 저장합니다. 오디오를 사용할 수 없는 환경에서도 주행은 가능합니다.

각 AI는 독립적인 운전 상태와 성격을 가집니다. NOVA는 공격형, VECTOR는 전략형, SOLAR는 균형형,
POLAR는 신중형, ORBIT는 추월형입니다. 기본 페이스·공격성·반응 속도·주행선에 더해 안전거리와 출발 반응도 다릅니다.
차량 간 접촉에 연루된 AI는 상대속도에 따라 사건당 5~25점을 감점하며, 같은 접촉이 이어지는 동안 중복 감점하지 않습니다.
두 차량이 0.6초 이상 떨어졌다가 접촉하면 새로운 사건입니다. 감점 직후에는 안전거리와 추월/합류 여유를 늘리고
공격적인 방어를 억제합니다. 조심하는 정도는 무사고 주행 중 서서히 줄며 점수는 레이스 끝까지 유지합니다.
피해/가해 책임을 판정하는 규칙이나 신경망 강화학습은 아니며, 각 차량의 접촉 기억을 사용하는 적응형 제어입니다.
ESC 메뉴의 ‘AI 성향 · 충돌 감점’에서 확인하며 재시작하면 초기화합니다.

앞의 ‘순위에 따른 최고속도’ 수치와 반복 선두 교환 결과는 이전 버전의 기록입니다. 이번 단계에서는
출발 5초 동안 AI의 유효 출력을 기본 플레이어의 98~102%로 제한하고, 5~22초에 걸쳐 기존 주행 출력으로 연결합니다.
순위 추격 보정은 12~35초에 걸쳐 서서히 적용하고 최고속도 상한은 110 → 104 m/s,
추격 추가 출력 상한은 35 → 15%로 줄였습니다. 주행 위치나 속도를 직접 바꾸지 않습니다.
기본 AI의 기존 코너 성능 보조는 유지되므로 전체 랩타임이 플레이어와 같아진다는 뜻은 아닙니다.

검증은 `npm test`와 `npm run build`로 실행합니다. 물리 주행·접촉 후 판단·중복 감점 방지·초기화,
오디오 텔레메트리와 오디오 그래프의 음소거/일시정지 처리를 검사합니다.
실제 브라우저 청취와 수동 플레이의 체감 조정은 별도 확인이 필요합니다.


## 영상 레퍼런스 기반 엔진 사운드 교체

사용자가 제공한 296.46초의 F1 25 엔진 비교 영상에서 Ferrari(40–70초), Honda RBPT(100–130초),
Mercedes(170–200초), Renault(245–280초) 구간을 분석했습니다. 24kHz 모노 분석용 신호에서 85ms 창을 사용해
주기 간격을 추정하고, 주변 주파수의 잡음을 제외한 48개 배음 크기를 저회전/고회전으로 집계했습니다.
측정한 주기 간격 중앙값은 각각 약 90.4 / 95.4 / 97.3 / 93.6 Hz입니다. 이는 녹화의 음향 측정값이며
실제 엔진 회전수나 제조사 전체의 물리적 특성을 직접 측정한 값은 아닙니다.

이 녹화에서 Ferrari는 4번째 및 상위 배음, Honda RBPT는 2·3번째 배음,
Mercedes는 3·4번째 배음, Renault는 2·3번째와 일부 상위 배음이 두드러졌습니다.
`EngineTimbres.ts`에 저장한 배음으로 Web Audio 주기파를 새로 합성합니다. 원본 영상이나 음성 파일은 게임에 포함하지 않습니다.
플레이어는 Ferrari 기준 음색이고, 상대 차량은 Honda RBPT → Mercedes → Renault → Ferrari 순서로 배정합니다.
서로 다른 제조사 이름은 참고 음색의 출처이며 라이선스 차량이나 공식 사운드팩을 뜻하지 않습니다.

기존 두 오실레이터의 단순 합산을 배음 주기파의 저회전/고회전 크로스페이드로 교체했습니다.

## 고음 밸런스 및 첫 시케인 밀집 주행 보완

독립된 고주파 보조음은 0.035 → 0.006으로 약 15.3dB 낮췄습니다. 엔진 경로에는 2.5kHz 기준 -5dB
고역 셸프를 두고, 부하에 따른 저역통과 필터 상한을 약 6.7 → 4.44kHz로 줄였습니다.
필터 Q를 0.5로 낮춰 좁은 주파수의 돌출을 억제합니다. 중저음 배음·변속음·제동/타이어음과 전체 음량 설정은 유지합니다.

기본 출발에서 다섯 AI가 레티필로에서 접촉하는 문제를 재현했습니다. 직선 추월의 상대 주행선 편차를
코너까지 유지하고, 다른 차선의 앞차를 제동 대상에서 제외하면서 같은 정점에 몰리는 것이 원인이었습니다.
첫 정점 약 360m 전부터 두 번째 정점 100m 뒤까지, 주변 차량이 있으면 추월/방어를 중단하고
기준 주행선으로 복귀합니다. 기존 옆 차량 합류 검사는 유지하며, 옆 차선의 앞차도 포함해
속도에 비례한 여유를 먼저 확보합니다. 정체 때 목표 속도의 5m/s 하한을 없애 브레이크로 양보할 수 있게 했습니다.
위치 이동이나 속도 강제 지정으로 차량을 분리하지 않습니다. 해당 구간 밖의 추월·방어 성향은 유지합니다.

물리 재현 시험: 기본 출발 25.92초, 좌우 그리드 반전 25.96초, 75m/s 밀집 접근 14.09초에
다섯 차량 모두 두 정점을 통과했으며, 각 시험에서 차량 접촉과 도로 이탈은 0회였습니다.
시간은 시험 시작부터 전체 차량의 1,180m 통과까지입니다. 사람의 충돌 유발 입력이나 모든 임의 배치에 대한 무사고 보장은 아닙니다.
앞의 장시간 대결에서 정해진 횟수의 선두 교환을 요구하던 검사는, 좁은 구간의 양보를 허용하는
근접 경쟁·주행 진척 검사로 바꿨습니다. 별도의 직선 추월 검사는 유지합니다.

## 차량별 독립 주행 AI

각 상대 차량은 별도의 `DriverAgent` 인스턴스를 가집니다. `Race`는 레이스 시간·순위·충돌 물리와
공정한 관측 시점을 관리하고, 각 에이전트는 자신의 주행 상태·목표 차량·상대 기억·반응 시계를 관리합니다.
같은 고정 물리 스텝에서 판단하는 AI는 모든 차량이 움직이기 전의 같은 위치/속도 사본을 관측합니다.
따라서 배열에서 먼저 계산된 차량이 뒤쪽 차량의 판단을 바꾸는 순서 의존성을 줄였습니다.

에이전트는 주행·추종·추월·방어·양보·복귀 상태를 상황에 따라 선택하고, 조향·가속·제동·ERS를 결정합니다.
NOVA의 공격성, VECTOR의 안전 여유, SOLAR의 균형, POLAR의 신중함, ORBIT의 추월 성향은
각 차량의 페이스·차선 선호·반응 주기·추월 방향 유지 시간에 반영합니다.
안전한 통로 검사와 몬차 첫 시케인의 양보/줄서기 규칙은 모든 에이전트에 적용합니다.

각 에이전트는 주변 차량의 간격·접근 속도·횡방향 움직임과 접촉 이력을 따로 기억합니다.
접촉 직후 1.25초간 새 추월·방어를 억제하고, 접촉 상대에 대해서는 잠시 횡방향 움직임을 고려해
추월 통로를 더 조심스럽게 선택합니다. 기존 충돌 감점과 안전거리 증가도 해당 에이전트에 적용됩니다.
다른 차량의 기억이나 감점을 복사하지 않으며, 레이스를 다시 시작하면 기억·상태·판단 횟수를 초기화합니다.
ESC 메뉴의 ‘AI 성향 · 충돌 감점’에 현재 행동 상태도 표시합니다.

검증: 다섯 에이전트의 소유권/메모리 분리, 반응 주기 차이, 관측 사본, 접촉 후 일시 양보와 재추월 판단,
초기화, 계산 순서를 뒤집은 출발의 동일성, 기존 물리 주행·직선 추월·근접 경쟁을 검사합니다.
독립 AI 적용 후에도 기본 출발·좌우 반전 출발·75m/s 밀집 접근의 첫 시케인 시험은 모두 접촉/도로 이탈 0회입니다.


## 첫 코너 제동 파동과 플레이어 주변 경쟁 보완

첫 시케인 접근 360m 전부터 큰 간격을 즉시 요구하던 설정은 뒤 차량들이 650m 부근에서 강하게 감속하게 했습니다.
이제 접근 거리에 따라 안전 여유를 점진적으로 늘리고, 앞차 속도와 남은 실제 제동 거리로 추종 속도를 제한합니다.
양보 제어의 반응도 완만하게 바꿔 줄 전체에 급제동이 전파되는 현상을 줄였습니다.
정지한 장애물에는 계속 멈출 수 있으며, 첫 시케인의 신규 추월/방어 억제와 합류 확인은 유지합니다.

기존의 순위별 최고속도 보정에 `PackDirector`를 더했습니다. 플레이어 속도를 현재 구간의 기준 속도로 나눠
주행 페이스를 추정하고 약 8초 시간 척도로 평활화합니다. 따라서 코너에서의 정상 감속이 다른 직선에 있는 차량을
같은 절대 속도로 감속시키지 않습니다. 플레이어와 차량별 실제 거리 차이, 순위당 약 14m의 목표 간격을 사용해
최고속도·추격 출력·코너 목표 페이스를 함께 조정합니다. 멀리 앞선 AI는 코너에서도 힘을 빼고,
뒤처진 모든 AI는 각자 간격에 맞춰 기본 경쟁 페이스와 추격 여유를 회복합니다.
보정은 출발 4~18초에 걸쳐 적용되며, 속도/페이스 변화도 연속적으로 반영합니다.
추격 상한은 104m/s, 추가 출력 15%, 기존 코너 페이스 상한 1.47 안에서 유지합니다.

차량 위치·속도·주행 거리는 강제로 바꾸지 않으며 플레이어 물리는 그대로입니다. 플레이어가 2초 이상 정지하거나
트랙 위치를 확인할 수 없을 때는 주변 경쟁 보정을 해제해 전체 차량이 플레이어를 기다리며 서 있지 않게 합니다.

검증: 기본/좌우 반전 출발 및 75m/s 밀집 접근은 첫 시케인에서 모두 접촉·도로 이탈 0회였습니다.
기본 출발의 뒤 차량 강한 제동(브레이크 >40%) 시작은 약 924m 이후이며, 이전에는 약 650m였습니다.
Stock 키보드 물리와 가이드/앞차 제동을 사용하는 기준 드라이버의 실제 3랩(377.4초)에서,
초기 30초 이후 약 97.6%의 시간 동안 다섯 AI가 모두 플레이어의 ±150m 안에 있었습니다.
완주 순간 간격은 약 +15 / -43 / -18 / -56 / -32m였고, 첫 코너 접근에서 10m/s 미만으로 기어가는 프레임은 0회였습니다.
이는 특정 기준 드라이버 재현 결과이며, 다른 주행 속도·사고·트랙 이탈에서는 간격이 일시적으로 더 벌어질 수 있습니다.


## 플레이어 선두일 때 지속 추격

플레이어가 1등인 경우에는 뒤에서 간격만 유지하는 대신 추월까지 이어지는 목표를 사용합니다.
2·3등의 목표는 플레이어보다 각각 12m / 3m 앞이며, 4~6등은 6m / 15m / 24m 뒤를 기준으로 더 조밀하게 추격합니다.
이 값은 속도 계획용 목표이고 실제 위치를 지정하지 않습니다. 플레이어가 선두에서 내려오면 일반 거리 보정으로 돌아갑니다.

플레이어 뒤에 있을 때는 거리가 줄어도 코너 페이스 우위를 잠시 유지하며, 거리와 공격 역할에 맞춰 직선 추격을 이어갑니다.
최고속도 104m/s·추격 추가 출력 15%·기존 코너 페이스 상한 1.47을 유지합니다.
선두 추격의 ERS 시작 기준은 주공격 차량 12 / 다른 추격 차량 22로 낮췄고, 사용 중 중단 기준은 기존 5입니다.
다른 순위 상황에서는 기존의 18/35 기준을 사용합니다. 감속·막힌 앞차·추월 통로·첫 시케인 안전 검사는 그대로 적용합니다.

재현 검증: stock 차량/키보드 물리와 직선 ERS를 사용하는 기준 드라이버에게 137~185m 선행 거리를 주었습니다.
일반 주행과 코너 목표 속도를 10% 높인 주행에서 실제 첫 AI 추월은 각각 27.8초 / 40.2초에 발생했습니다.
변경 전 같은 조건은 약 125.9초 / 117.2초였습니다. 플레이어가 선두인 측정 구간 중 추격차가 25m 안에 있던 비율은
각각 약 65% / 89%입니다. 선두가 바뀐 시간은 이 비율에서 제외합니다.
180초 종료 시 두 시험 모두 다섯 상대 차량이 플레이어의 약 ±56m 안에 있었습니다.
첫 시케인 세 가지 밀집 시험과 기존 3랩 근접 경쟁·조기 정지 방지 검사도 유지합니다.


## 90초 첫 랩 / 85초 주행 대응

이전 선두 추격 검증은 약 110~120초의 stock 기준 드라이버였으며, 85초 주행의 검증으로 사용할 수 없었습니다.
현재는 기존 차량 물리로 89.98 / 85.64 / 85.64초 주행 기록을 생성해 같은 궤적을 기준 차량으로 재생하고,
상대 AI 다섯 대가 각각 물리 가속·조향·제동·접촉을 수행하게 하는 회귀 검사를 추가했습니다.
기준 기록은 기존 AI 벤치마크와 같은 grip 1.4 / power 1.35 시험 차량으로 만들었고 첫 출발에 2초 지연을 포함합니다.
게임의 플레이어 성능은 변경하지 않습니다. 기준 궤적은 충돌에 반응하지 않는 시험용 고스트이며 AI 위치는 재배치하지 않습니다.

직선 속도는 상한에서 비슷해지므로 평균 속도 비율만으로는 빠른 코너 페이스가 사라지는 문제가 있었습니다.
이제 정상 선회(충분한 횡가속·낮은 제동·작은 종가속)에서 얻은 코너 페이스를 따로 유지하고,
94초 미만으로 완주한 실제 랩 기록도 반영합니다. 첫 랩은 출발 손실 약 4초를 보정하며,
상대 코너 페이스의 초기 하향 보정은 16~28초에 걸쳐 적용해 출발 직선만 보고 너무 일찍 난도를 낮추지 않습니다.
재시작 시 랩/코너 추정값과 보조값은 초기화합니다.

빠른 페이스가 확인되면 상대 AI에 한해 접지 보조를 기존 1.4에서 최대 1.5로 부드럽게 높입니다.
뒤처진 AI의 코너 페이스 상한은 최대 1.53, 추격 추가 출력은 최대 35%로 확장하며 최고속도 상한 104m/s는 유지합니다.
보통 속도에서는 기존 1.47 / 15% 범위를 사용합니다. 앞선 차량에는 거리 차이에 따른 완화가 계속 적용됩니다.
플레이어의 접지·출력·속도·주행 거리는 보정하지 않습니다.

상승한 직선 속도에 맞춰 300m 앞의 실제 코너 속도와 실제 제동력을 다시 확인합니다.
빠른 AI는 기준 주행선을 우선하고, 속도 차이가 부족한 추월 시도를 억제하며,
추월 전 약 3.5초 분량의 직선 여유를 확인합니다. 연속 시케인의 줄서기/합류 검사는 레티필로뿐 아니라
로지아·아스카리에도 적용합니다. 빠른 모드의 간격은 짧게 하되, 실제 제동 거리와 최소 여유를 계속 검사합니다.

검증 결과: 일반 그리드에서 3랩 종료 시 간격 +25 / +65 / +48 / +137 / +93m,
180~236m 뒤에서 출발한 순수 추격에서는 +25 / +63 / +43 / +91 / +129m였습니다(양수는 플레이어 뒤).
순수 추격 시험은 다섯 AI 모두 접촉·도로 이탈 0회입니다. 그리드 시험은 고스트와 상호 작용하는 과정에서
일부 접촉과 NOVA 약 1.2% 프레임의 도로 이탈이 있어, 모든 배치의 무사고를 뜻하지 않습니다.
기존 첫 시케인의 세 가지 시험은 계속 접촉·도로 이탈 0회이며, 보통 속도의 3랩 근접 경쟁·조기 정지 방지 검증도 유지합니다.
일반 속도 선두 시험의 최종 간격은 공통 대열 기준인 150m로 검사하고, 별도로 90/85초 고속 추격 검사를 추가했습니다.

## 묵직한 배기 울림과 가속 맥동

엔진에 회전수에 맞춰 움직이는 32~72Hz 저음 배기층을 추가했습니다. 두 번째·세 번째 배음을 함께 사용하고
220Hz 저역통과 필터로 다듬어 60~200Hz의 몸통도 들리게 합니다. 엔진 경로의 180Hz 이하에는 +2.5dB 셸프를 적용했습니다.
가속 부하에 따라 저음이 강해지고, 작은 오디오 주파수 변조로 엔진의 미세한 거친 맥동을 만듭니다.
가속 시작과 상단 변속 후 동력이 다시 걸릴 때 짧은 저음 충격을 더하고 약 70ms의 시간 척도로 감쇠합니다.
별도의 느린 심장박동음을 재생하는 효과가 아니라 엔진 동작에 반응하는 배기층입니다.

주변 AI의 추가 저음은 플레이어의 55%로 낮춘 뒤 기존 거리 감쇠와 패닝을 적용합니다.
기존 고역 -5dB와 고음 보조음 제한은 유지하며, 새 저음도 기존 엔진 믹서·컴프레서·전체 음량/음소거 경로를 통과합니다.
지속 가속 중 과도한 증폭이 남지 않는지, 변속 충격·변조 깊이·음소거·일시정지를 자동 검사합니다.
실제 청취 인상은 출력 장치의 저음 재생 능력과 음량에 따라 다를 수 있습니다.


## 주행 연출 1단계

제동 때 노즈 다이브와 앞쪽으로 쏠리는 시점, 가속 때의 반대 움직임, 선회 때의 약한 기울기를 더했습니다.
최대 강도의 순수 제동 회전은 약 2.5도·선회 약 0.44도, 제동 높이 변화는 최대 7.2cm입니다.
기본 60%에서도 변속 순간 짧은 시점 충격과 운전대의 반동을 표시하며, 약 0.4초 안에 감쇠합니다.
평상시 고속 주행에는 작은 노면 진동이 있고, 실제 연석에서는 더 강한 수직 진동과 노면 마찰음이 발생합니다.
연석 블록 충격은 서스펜션 반응으로 완화해 30/60fps에서도 보이는 약 4~13Hz의 움직임으로 표현합니다.
연석 판정은 렌더링에 사용한 구간과 폭(중심 10.35m / 폭 1.4m)을 공유하고, 앞뒤/좌우 바퀴의 겹침을 확인합니다.
직선의 단순 도로 가장자리에서는 연석 효과가 발생하지 않습니다.

카메라의 변속 충격, 운전대 기어/RPM 표시, 플레이어 엔진음은 같은 오디오 전용 변속 상태를 사용합니다.
기어비는 약 98/129/159/189/224/259/294km/h에서 상향 변속하고, 하향 변속에는 각 경계의 84% 속도를 사용합니다.
하향 변속 간격은 130ms로 강한 제동을 따라가며, 기어가 바뀌면 80ms 화면 갱신 간격과 관계없이 즉시 표시합니다.
출발 대기 시 실제 선택된 1단을 표시하며, 속도만으로 기어를 다시 계산하거나 N을 표시하지 않습니다.
속도에 따른 바람 소리는 정지 시 꺼지고 고속에서 점진적으로 커집니다. 900Hz의 넓은 대역 잡음이며,
사용자 청취 피드백에 맞춰 강화했던 바람 음량의 50%로 조정했습니다(직전 버전 대비 약 -6dB).
기존 엔진음과 같은 음량·음소거 경로를 사용합니다.
브레이크·타이어 물리·실제 가속과 AI 성능은 변경하지 않습니다. 차량 바운스는 모델에만 적용합니다.

ESC 메뉴의 ‘주행 진동’에서 추가 연출을 0~100%로 조절하고 0%로 끌 수 있습니다. 기본값은 60%이며,
OS/브라우저가 움직임 감소를 요청하면 저장된 설정이 없는 첫 실행에서는 0%로 시작합니다.
설정은 브라우저에 저장합니다. 0%는 바람/연석 소리를 끄지 않으며, 소리는 기존 음량/M 음소거로 조절합니다.
일시정지·완주 시 새 연출과 소리를 멈추며 복귀/재시작 때 변속 충격 상태를 초기화합니다.

자동 검증: 바퀴와 실제 연석의 접촉, 직선/도로 중심의 무진동, 제동 방향과 시야 중앙 도로 투영,
강도 0%, 30/60/144fps에서의 감쇠 결과, 변속 충격, 카메라/엔진음 RPM 일치, 바람·연석음의 음소거/일시정지를 검사합니다.
기본 강도에서 변속 충격이 720px 높이의 화면에서 최소 4px 이상, 최대 20px 미만 움직이는지,
실제로 캔버스에 그려진 기어가 같은 프레임의 엔진 상태와 일치하는지, 200/300km/h에서 바람 음량의 하한도 검사합니다.
기존 90/85초 주행·AI 추격 회귀 검사도 유지합니다. 실제 브라우저 화면·출력 장치의 체감은 자동 검증과 별도입니다.

## 그래픽 2차 개선: 차량·서킷 디테일과 품질 설정

차량에 사이드포드 흡기구, 냉각 슬롯, 플로어 베인, 에어박스와 카메라 포드를 추가했습니다.
타이어의 비율과 둥근 숄더, 림·브레이크 디스크·측면 문구를 다듬고 바퀴 전체가 X축 차축을 중심으로 회전하게 했습니다.
바퀴 부품을 재질별로 병합해 한 차량의 기본 메시 수를 40개에서 32개로 줄였습니다.
삼각형 수는 15,036개에서 18,212개로 늘었으며, 메시 감소가 실제 기기에서 같은 비율의 FPS 향상을 보장하지는 않습니다.

관람석을 트랙과 평행하게 재배치하고 좌석·지붕 기둥을 추가했습니다. 피트 차고의 셔터·프레임과
안전 펜스는 재사용 재질과 인스턴싱을 사용합니다. 펜스는 약 120m 단위로 나눠 플레이어 근처만 표시하며
뒤쪽도 함께 남겨 백미러에서 보이도록 합니다. 트랙 형상, 연석 판정, 차량 물리와 AI는 바꾸지 않았습니다.

ESC → ‘그래픽 품질’에서 자동·낮음·보통·높음을 고를 수 있고 선택은 브라우저에 저장합니다.
반사는 기존 HDR 하늘의 PBR 환경 반사이며, 실시간 차량/노면 반사를 추가한 것은 아닙니다.
품질이 바뀔 때만 환경 반사를 다시 생성하고 이전 하늘·반사·그림자 버퍼는 해제합니다.

| --- | --- | --- | --- | --- | --- |

실제 해상도는 기기 픽셀 비율과 화면 크기를 상한으로 합니다. 백미러는 화면의 종횡비를 유지하며,
장면을 새로 캡처하지 않는 프레임에도 저장된 거울 영상을 표시합니다. 주 화면의 그림자를 재사용합니다.
자동은 메모리·코어·GPU 텍스처 한도로 초기 품질을 정하고, 주행 시작 3초 후부터 2초 단위 평균을 확인합니다.
두 구간 연속 46fps 미만이면 한 단계 낮추고 다시 3초 안정화 시간을 둡니다. 일시정지·배경 탭의 긴 공백은 제외합니다.
반복적인 화질 변화를 피하려고 자동 상향은 하지 않으며, 자동을 다시 선택하면 초기 권장 품질부터 재평가합니다.
수동으로 고른 품질은 덮어쓰지 않습니다.

검증: 기존 주행/90·85초 AI 회귀 검사, 수동 품질 유지·자동 하향·일시정지 보호,
백미러 캡처 횟수·종횡비·렌더러 상태 복구, 바퀴의 지면 간격과 회전축, 관람석 방향,
거리별 디테일 재표시, HDR 데이터와 반사/그림자 리소스 해제를 자동 검사합니다.
차량은 CPU 기반 기하 미리보기로 전후 형태도 확인했습니다. 현재 환경에는 브라우저/GPU 미리보기 도구가 없어
이번 변경의 실제 WebGL 화면과 기기별 FPS는 직접 검증하지 못했습니다.


## 연속 연석과 슬릭 타이어 형태 수정

연석의 회전된 직사각형 인스턴스를 제거하고, 트랙 곡선을 따라 꼭짓점을 공유하는 하나의 연속 리본으로 교체했습니다.
적색·백색 경계는 반복 도장 텍스처로 표현하며 블록의 틈이나 겹침이 생기지 않습니다.
연석 높이는 안쪽 4cm / 낮은 봉우리 11.5cm / 바깥쪽 -7.8cm로 도로·잔디에 완만히 연결하고, 시작·끝도 낮아집니다.
기존 곡률 판정이 만든 30m 이하의 짧은 공백을 연결해 코너 연석이 67개 작은 구간에서 15개 연속 구간으로 정리됐습니다.

급한 코너 안쪽의 경계가 접히지 않도록 화면에 그리는 도로 가장자리와 흰 선·연석에 같은 24m 구간 평균 방향을 사용합니다.
실제 중심 경로, AI 주행선, 조향·가속·접지는 변경하지 않습니다. 연석 진동과 소리는 새 연석의 구간·폭을 미리 계산해
바퀴가 실제로 그려진 띠와 겹치는 위치에서 발생하도록 맞췄습니다.

타이어는 원통에 숄더 링을 덧붙이던 구조에서 하나의 회전 곡면으로 바꿨습니다.
중앙 트레드는 폭 방향으로 평평하고 옆면으로 부드럽게 이어지며, 고무의 띠 모양 요철과 외곽 장식선도 제거했습니다.
측면 글자는 고무 곡면에서 0.35mm만 띄워 그리며 평평한 원판이나 돌출 테두리를 사용하지 않습니다.
금속 림은 타이어 안쪽에 유지하고, 타이어 반경 0.455m·회전축과 기존 바퀴별 병합은 유지합니다.
차량 기본 메시 수는 32개, 삼각형은 21,284개입니다.

자동 검사로 모든 연석 삼각형이 위를 향하는지, 도장 구간이 꼭짓점을 공유하는지, 폭·높이·접촉 위치가 맞는지 확인합니다.
슬릭 트레드 반경, 옆면 문구의 밀착, 미세 고무 질감과 기존 주행·AI 회귀 검사도 수행합니다.
연석은 CPU 기하 미리보기로 형태를 확인했으며 실제 브라우저/GPU 화면은 현재 환경에서 직접 확인하지 못했습니다.


## F1 방식 출발 신호와 배경·노면 3차 개선

숫자 카운트다운을 다섯 열의 빨간 출발등(열마다 두 등)으로 바꿨습니다. 첫 등은 0.6초 후 켜지고,
이후 1초 간격으로 다음 열이 켜집니다. 다섯 열이 켜진 뒤 0.8~2.4초의 무작위 대기를 거쳐 모두 소등되면 출발합니다.
총 대기는 5.4~7.0초입니다. 트랙 위 신호등·차량 출발·경기 타이머가 같은 시뮬레이션 상태를 사용합니다.
일시정지 중에는 신호 시간이 진행되지 않으며 빨간불 동안 플레이어와 AI는 출발하지 않습니다.

각 점등에는 660Hz의 짧은 게임용 신호음, 소등에는 990Hz의 구분되는 출발음을 추가했습니다.
실제 F1 공식 음원을 삽입한 것은 아닙니다. 시작 버튼/키 입력에서 기존 Web Audio를 해제하고,
출발 대기 중 엔진은 공회전합니다. 신호음도 기존 음량/M 음소거에 따르며 일시정지·재시작 시 예약된 소리를 취소합니다.
같은 등은 프레임마다 반복해서 소리 나지 않습니다.

기존 합성 하늘을 기본 대체 화면으로 남기고, 로컬에 포함한 HDRI Haven/Poly Haven의 CC0 공원 HDR 사진을
정상 배경과 PBR 환경 조명에 사용합니다. 원본은 약 1.59MB이며 게임과 함께 배포되어 외부 이미지 서버가 필요 없습니다.
사진의 태양 위치에 맞춰 실제 그림자 광원 방향도 맞춥니다. 품질별 256/512/1024 해상도로 선형 광량을 평균해 반사 입력을 만들고,
로딩 도중 품질이 바뀌어도 최종 설정을 적용합니다. 사진 로딩에 실패하면 합성 하늘로 계속 진행합니다.
사진은 일반 공원이며 몬차 현지 촬영/스캔 자료는 아닙니다. 출처와 CC0 정보는 `src/assets/ATTRIBUTION.md`에 있습니다.

아스팔트·잔디·자갈에는 512px 재질을 사용합니다. 노면과 넓은 잔디의 월드 좌표 색 변화를 더해 작은 타일이
규칙적으로 반복되는 인상을 줄였습니다. 제동/코너 구역에는 곡선을 따르는 고무 흔적과 바깥쪽 자갈 띠를 추가했습니다.
나무는 하나의 각진 덩어리에서 여러 수관과 잎 모양의 알파 컷아웃으로 바꿨으며, 빛과 그림자가 잎 사이로 통과합니다.
약 180m 구간별 인스턴싱을 사용해 화면과 그림자 범위 밖의 숲을 제외할 수 있도록 했습니다.
이 변경은 표면 표시이며 플레이어/AI의 주행선, 접지, 연석 형태와 기존 바람 음량을 바꾸지 않습니다.

검증은 기존 90/85초 AI 회귀 검사에 더해 30~144fps 출발 시각, 빨간불 동안 정차·타이머 유지,
HUD 신호등 중복 제거와 트랙 등, 점등/소등 신호음 중복 방지·일시정지·음소거, HDR 원본 디코딩·품질 전환·오류 시 대체 화면,
노면 색 변화와 숲 배치/그림자 재질을 검사합니다. 현재 환경에는 브라우저/GPU 미리보기가 없어 실제 WebGL 화면과 청취는 직접 확인하지 못했습니다.


## 짧은 코너 연석 재구성과 변속 반동 조정

변속 충격의 공통 진폭을 0.15에서 0.105로 바꿔 화면·운전대의 변속 반동 성분을 직전의 70%로 낮췄습니다.
제동·노면·연석 진동의 크기와 변속음은 이 변경의 대상이 아닙니다.

이전 연석은 중심 위치와 가장자리 방향을 서로 다른 방식으로 평활화해 짧은 코너에서 폭이 일그러졌습니다.
이제 화면용 도로 중심을 1m 간격의 주기적 C2 B-스플라인으로 만들고, 동일한 곡선의 미분으로 가장자리 방향을 구합니다.
6m 가우시안 평활화로 소스 경로의 미세한 꺾임을 없앴습니다. 실제 물리 중심선·AI 경로는 기존 것을 사용합니다.
시험상 화면 중심의 최대 이동은 약 1.63m이며, 기존 주행선의 화면 중심 기준 최대 횡거리는 7.81m 이내입니다(도로 반폭 10m).
노면·흰 선·고무 흔적·자갈도 이 화면용 곡선과 정렬했습니다.

연석은 네 가장자리의 중점 오차가 1mm, 방향 변화가 2도를 넘으면 자동 세분화합니다.
현재 코스의 작은 코너는 중심선 진행 약 0.194m 간격까지 나뉘며, 연석 삼각형은 총 78,496개입니다.
도색 길이는 종전 약 3.1m에서 0.75m로 낮추고 연석 각 측면의 실제 호 길이에 따라 반복해 짧은 곡선에서 늘어짐을 줄였습니다.
바퀴 접촉과 소리/진동 판정도 동일한 세분화 점을 사용합니다.

검증: 연석 전체 면의 위쪽 방향·퇴화 방지, 실제 중점 오차, 스플라인 연결부와 코스 이음새의 방향 연속성,
기존 주행선의 도로 내부 유지와 90/85초 AI 회귀 검사를 확인합니다. CPU 기하 미리보기에서 첫 시케인의
안쪽 연석을 확인했으며 실제 브라우저/GPU 화면은 현재 환경에서 직접 확인하지 못했습니다.

## 배경의 이동감과 렌더링 최적화

표시용 배경에서 사진에 고정된 수목·잔디·지평선을 제외했습니다. 사진은 PBR 조명에 유지하되,
화면에는 상단 하늘만 이용한 512px 배경과 실제 3D 수목을 표시합니다. 수목을 24~44 / 44~84 / 80~125m의
세 거리층으로 배치하고 피트·관람석의 공간을 비워 차량의 이동에 따라 가까운 나무가 빠르게 지나가는 실제 시차를 만듭니다.
배경 하늘 해상도는 반사 품질과 분리했으며 같은 반사 해상도의 품질 전환에서는 환경 반사를 다시 굽지 않습니다.

도로·연석은 원래의 모든 삼각형과 버텍스 버퍼를 유지한 채 약 100m 구간별 인덱스와 경계를 만듭니다.
화면 밖 구간은 GPU에 제출하지 않습니다. 정적 서킷의 변환 행렬과 경계도 시작 시 계산하고 고정합니다.
먼 수관은 400개 대신 60개의 삼각형을 사용하고, 숲의 거리·그림자 범위를 품질에 맞춰 제한합니다.
HUD와 미니맵·배경 가시성 갱신은 10Hz로 제한하되, 출발등과 계기판 기어 변경은 계속 즉시 표시합니다.
연석 접촉 검사도 근처에 연석이 없는 직선과 도로 중앙에서는 상세 바퀴 검색을 생략합니다.

낮음·보통에서는 차량을 따라가는 가벼운 접지 그림자를 사용합니다. 서킷의 정적인 방향광 그림자는
차량이 약 8m 이동하거나 태양·품질이 바뀔 때만 다시 만듭니다. 갱신하지 않는 동안 광원과 그림자 볼륨도 고정해
그림자가 밀리는 문제를 피합니다. 높음에서는 기존 차량의 방향광 그림자를 유지합니다.
백미러는 낮음 15 / 보통 20 / 높음 30Hz, 최대 320×90 / 400×112 / 512×144로 제한하며 표시 영상은 매 프레임 합성합니다.
대기·일시정지에는 백미러 장면을 다시 캡처하지 않습니다.

| 설정 | 픽셀 비율 상한 / 픽셀 예산 | 그림자 | 반사 원본 | 백미러 거리 | 주 시야 거리 |
| --- | --- | --- | --- | --- | --- |
| 낮음 | 1.0 / 120만 | 512² | 256 | 220m | 800m |
| 보통 | 1.1 / 210만 | 768² | 512 | 320m | 1100m |
| 높음 | 1.35 / 360만 | 1024² | 512 | 500m | 1400m |

자동은 메모리/코어 수만으로 높은 GPU 성능을 가정하지 않고 보통부터 시작합니다(저사양은 낮음).
0.75초 안정화 후 0.75초 구간에서 두 번 연속 50fps 미만이거나 한 구간 28fps 미만이면 품질을 낮춥니다.
150ms를 넘는 프레임도 무조건 배경 탭으로 버리지 않으며, 주행 중 세 프레임 연속 발생하면 바로 낮춥니다.
낮음에서도 부족하면 화면 해상도 배율을 최소 65%까지 줄입니다. 수동 선택은 덮어쓰지 않습니다.

이전 커밋 `1fd458a`와 같은 여섯 주행 위치의 보통 품질 카메라를 비교한 CPU 기하 검사에서,
서킷 배경의 평균 제출 삼각형은 397,303 → 164,580개(약 59% 감소), 도로/연석은 124,848 → 43,065개(약 66% 감소)였습니다.
실제 기기의 GPU 시간이나 FPS 측정값은 아닙니다. 곡선 정밀도·기존 주행/AI/출발 검사와 함께 구간별 삼각형 보존,
정적 행렬, 픽셀 예산, 연속 느린 프레임 대응, 그림자 캐시, 3D 수목의 실제 화면상 이동을 자동 검사합니다.
현재 환경에는 브라우저/GPU 미리보기가 없어 실제 기기 FPS와 최종 화면은 직접 확인하지 못했습니다.


## 출발 신호를 트랙 구조물로 통합

화면 상단의 빨간 출발등과 중앙 안내 문구/신호등 UI를 제거했습니다. 출발 신호는 출발선 앞
`start-gantry` 구조물 아래의 다섯 열/열마다 두 개 렌즈에서만 보입니다. 검은 분리형 하우징과
조금 넓힌 렌즈로 배경과 구분하고, 자체 발광 렌즈에는 톤 매핑을 적용하지 않아 낮에도 점등을 구별합니다.
기존 출발 신호음, 순차 점등/동시 소등, AI·플레이어 출발 시각, 일시정지 처리는 유지합니다.
추가 조명이나 블룸 패스 없이 하우징은 병합한 메시 하나로 그립니다.

검증: 전체 주행/AI/출발음 회귀 검사와 `/f1/` 경로 빌드 통과. 두 카메라 시점과 운전석 높이
1.5/1.8/2.8m에서 렌즈 열 개가 화면 범위 안에 있고, 운전자를 향하며, 하우징에 가려지지 않음을
Three.js 투영·레이 검사로 확인했습니다. 실제 브라우저/GPU 화면 검사는 수행하지 못했습니다.


## 곡선 배리어·1.5m 운전석·밀집 관중석

배리어의 4.4m 직육면체 반복을 폐곡선 단면 메시로 교체했습니다. 시각 도로에서 16.2m 떨어진
경로의 급한 안쪽 오프셋 루프를 잘라내고, 호 길이 기준으로 작은 접합부를 둥글게 처리합니다.
벽 두께 0.55m, 높이 1.2m이며 구간별 최대 길이 3m/단순화 오차 3mm로 생성합니다.
약 100m 메시 단위로 화면 밖을 제외하고, 광고와 패널 이음새는 같은 재질의 UV로 표현합니다.
뒤쪽 안전 펜스도 벽의 모든 곡선 행을 공유해 긴 펜스 면이 코너를 가로지르지 않도록 했습니다.
최종 벽은 44,320개 삼각형이며 양쪽 가장자리와 랩 이음새의 교차/틈, 붕괴한 면, 노면 여유를 검사합니다.

운전석 기준 높이를 1.5m로 고정하고 일시정지 메뉴의 높이 조절과 콜백을 제거했습니다.
카메라 헤일로 아치를 위로 배치하고 중앙 지지대 반지름을 0.024m로 줄였으며 외부 차량 모델의
아치·지지대 연결도 맞췄습니다. 기존 주행 진동과 변속 진동 30% 감소 설정은 유지합니다.

출발 직선에 `.0175`, `.040`, `.052` 진행 지점의 관중석 세 개를 추가했습니다.
직선 구간 관중석은 2→5개, 전체는 9→12개입니다. 6열×60석을 모두 채워 전체 4,320명의
관중을 인스턴싱으로 표시하며 복장·피부색·키를 조금씩 다르게 구성했습니다.
관중석 위치 목록을 수목 배제에도 공유해 지붕을 뚫고 나무가 자라지 않도록 했습니다.
관중은 품질에 따라 65/100/160m 안에서 머리와 상체를 분리한 형태로, 그 밖에서는 단순한
형태로 표시하며 200/320/500m 밖에서는 제외합니다(관중석 반경 32m 보정).
관중별 그림자는 생성하지 않고 형상과 재질을 관중석 사이에서도 공유합니다.

검증: 전체 회귀 검사와 `/f1/` 빌드 통과. 실제 렌더링에 사용하는 Float32 벽 가장자리의
자가 교차 0회, 닫힌 이음새 일치, 노면 중앙선과 15.5m 이상 간격, 새 지붕 사이 간격,
관중 수와 근거리/원거리/숨김 전환, 고정 시야와 높이 조절 UI 제거를 확인했습니다.
별도 CPU 투영으로 헤일로를 검토했으며 실제 브라우저/GPU 화면과 FPS는 직접 측정하지 못했습니다.


## F1 25 참고 헤일로·낮은 연석·키보드 보정 조정

제공된 인게임 사진의 실루엣에 맞춰 헤일로를 화면 아래쪽에서 운전석을 감싸는 아치로
다시 구성했습니다. 원형 파이프 대신 모서리가 둥근 납작한 단면을 사용하고, 짧은 중앙
블레이드만 아치 아래에서 노즈로 연결합니다. 아치 위 안테나/돌출물은 없으며 운전석
높이는 1.5m로 유지합니다. 외부 차량에도 같은 단면 생성기를 사용합니다.
기본 카메라 투영에서 아치 윗면은 화면 높이 약 63%, 중앙 지지대 폭은 화면 폭 약 0.7%입니다.

연석의 최고 높이를 0.115→0.055m로 낮췄습니다. 노면 0.035m를 기준으로 솟는 높이는
8→2cm이고, 안쪽 시작은 노면과 맞닿습니다. 기존 곡선 경로·패턴 간격·잔디 연결을 유지하며
연석의 차체 반응은 0.026/0.011m 합성 계수에서 0.010/0.004m로 줄였습니다.

키보드 주행은 코너 제동 보정의 90%만 적용하고, 미끄러짐 안정화 토크의 계수/상한을
20% 줄였습니다. 강한 제동과 조향을 동시에 계속 입력하면 접지 여유가 줄어들므로
직선에서 먼저 감속하고 코너에 들어가며 브레이크를 풀어야 합니다. 조향 입력 램프,
직선 제동력, 플레이어/AI 기본 접지력·출력, 기존 권장 주행선과 AI 보정은 유지합니다.

120Hz 물리 재현에서 40m/s 진입 후 1초간 풀 브레이크+풀 조향의 최고 슬립각은
5.35→7.55도였고, 입력 해제 2초 후 횡속도/요 레이트는 안정적으로 회복했습니다.
먼저 제동 후 조향한 경우에는 5.88→5.89도, 60m/s 무제동 조향은 2.23도로 유지했습니다.
전체 검사에는 권장 속도 완주·키보드 복합 입력/회복·근접 AI·90/85초 추격·평평한 연석과
화면 아래 헤일로 실루엣/렌더링 방향/유효 면/UV를 포함합니다. CPU 투영으로 형태를 검토했으며
실제 브라우저/GPU 화면과 키보드 체감은 직접 확인하지 못했습니다.


## RPM 계기판 동기화와 변속등 기준 수정

기어비/RPM 상태는 `9c8e4bf` 이후의 기존 계산과 동일합니다. 60fps 일정 가속 재현에서
변속 후 0.12초 RPM은 2단 9,309 / 3단 9,879 / 4단 10,166 / 5단 10,254 /
6단 10,465 / 7단 10,633 / 8단 10,759였지만, 예전 6,500~12,000RPM 표시등은
각각 8/10/10/11/11/12/12개가 남았습니다. 기어 전환 직후 한 번 갱신하고 80ms 동안
기다리던 방식도 짧은 RPM 하강을 늦게 보여줄 수 있었습니다.

계기판 오른쪽 아래에 공유 엔진 상태의 실제 RPM 숫자를 추가했습니다. 숫자와 표시등,
기어, 플레이어 엔진음은 동일한 `DrivingFeedback.engine`을 사용합니다. 표시등은
