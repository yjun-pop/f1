# 서킷 환경 제작용 참고 자료

조사일: 2026-11-05. 대상: 게임에 포함된 8개 서킷.

사용자가 사진을 하나씩 업로드할 것을 전제로 하지 않는다. 공개 이미지 검색으로 사진 원문과 공식 설명을 직접 찾는다. 이 목록은 자료의 접근·검증 수준을 기록한다. 구현과 한계는 CIRCUIT_AUTHENTICITY.md를 함께 본다.

## 접근 상태와 선별 기준

- 아래 사진 링크는 웹 이미지 검색에서 찾았다. 검색 도구는 실제 이미지 픽셀 대신 이미지 URL·설명 텍스트를 반환했다. 따라서 **사진을 직접 시각 검토했다고 표시하지 않는다.**
- 공식 사이트·제작사 설명은 검색 및 페이지 열람으로 읽었다. 문서로 확인된 구조적 사실과 이미지 검색 설명의 추정은 구분한다.
- Google 이미지 검색 페이지 직접 열기는 도구에서 실패했다. 아래 자료는 사용 가능한 웹 이미지 검색으로 수집했다. Google을 직접 열어 검토했다고 주장하지 않는다.
- 이미지 검색에 나온 Getty의 홈페이지 링크만 있는 결과, Pinterest 재게시물, 생성형 이미지로 의심되는 부동산 홍보 사진은 모델링 기준에서 제외한다.
- 2011년 일반 도로 사진을 현재 F1 임시 방호벽/조명 배치의 근거로 사용하지 않는다. 오래된 사진은 영구 건축 구조 참고 후보로만 유지한다.
- 참고 사진을 게임 텍스처에 복사하거나 배포하지 않았다. 사진의 위치·형태를 대조하는 참고 자료로 사용한다.

## 1. 모나코 — 첫 제작 기준 구간

선정 구간: Portier → Fairmont 하부 터널 → 출구와 Nouvelle Chicane 연결부.

자료:

- [Fairmont 외관·해안 쪽 전경](https://www.granturismoevents.com/laguida-fairmont-a-hotel-in-monte-carlo-monaco/) · [이미지 원본](https://www.granturismoevents.com/_Pages/3000/_Slider/890011.jpg)
- [터널 입구를 포함한 현지 여행 사진](https://www.travelsvenue.com/2018/09/visit-monaco.html) · [이미지 원본](https://1.bp.blogspot.com/-A6pafj1ivPQ/W54EXH3sEhI/AAAAAAAAc-g/aFnIEAIjk1cPLJxx0EhiCNR74tQb0XjVgCKgBGAs/s1600/Visiting-Monaco-12.jpg)
- [2011년 터널 실사 및 촬영 정보](https://commons.wikimedia.org/wiki/File:Tunnel_stradale_sotto_l%27hotel_Fairmont,_Monaco.jpg)
- [실제 터널 조명 공급사 SGM 프로젝트 설명](https://www.sgmlighting.com/projects/famous-tunnel-lit-by-sgm-fixtures-for-the-monaco-formula-1-grand-prix)
- [FIA 2025 회로·피트·구역 지도](https://www.fia.com/system/files/decision-document/2025_monaco_grand_prix_-_race_directors_event_notes_-_circuit_map_pit_lane_map_ers_battery_containment_area_red_zones.pdf)

문서로 확인한 사실: 터널은 호텔 하부를 지나며, 해안 쪽 측면 일부가 개방되어 있다. 조명 공급사는 경기용 LED의 주광색에 가까운 출력과 바닷물 노출 문제를 설명한다. 따라서 기존의 독립된 폐쇄형 회색 통로는 실제 장소와 구조적으로 맞지 않는다.

사진으로 추가 대조할 항목: 호텔 층·발코니의 외곽, 입구와 출구의 높이 관계, 실제 천장 보 방향, 기둥과 해측 개구부, 임시 차폐물의 경기 연도별 차이. 정확한 기둥 간격과 터널 폭은 아직 실측 확인하지 않았다.

대조 대상: Club–Abbey 쪽 Wing 전체 실루엣, 피트 후면 작업 공간, 고속 연속 코너 바깥 관중석, 넓은 잔디·서비스 포장 공간. 주변을 균일한 숲으로 채우지 않는다.

- [Raidillon 관중석 시공사 Wust의 실제 프로젝트·사진](https://www.wust.be/fr/projets/tribune-raidillon)
- [Wallonia 지역 공공 홍보 자료·항공사진](https://www.wallonia.be/en/news/spa-francorchamps-most-beautiful-circuit-world)

문서로 확인한 사실: 라디옹 관중석은 여러 층의 시설과 덮인 관람 구역을 가진 구조다. 공식 지도는 코스의 거리별 표고를 제공한다.

대조 대상: 골짜기 진입→상승→능선 너머의 연속적인 높이 관계, 경사에 연결되는 관중석 기단과 뒤쪽 숲, Pouhon 주변의 깊은 수목. 노면이 평면인 기존 게임을 배경 산만으로 실제와 같다고 할 수 없다. 노면 변경은 별도 영향 설명 및 해당 구간 주행 검사가 필요하다.

대조 대상: Senna S의 내리막, 외곽 주거지와 운영 시설의 거리, 피트와 관중석, Junção 이후 오르막. 주거 건물을 전 구간 도로 바로 옆에 붙이지 않는다. 검색 결과의 생성형 이미지 의심 파일명/출처는 제외했다.

## 다음 제작 판단에 사용할 원칙

1. 모나코 호텔·터널 연결부에서 먼저 구조 모델의 기준을 만든다.
2. 사진 원본을 직접 확인하기 전에는 개구부 치수·층수·거리의 사진 기반 검증을 완료했다고 보고하지 않는다.
3. 공식 텍스트로 이미 확인된 구조적 오류는 별도 기록하며, 이미지 접근 문제를 이유로 조사 전체를 사용자에게 넘기지 않는다.
4. 구현·배포 상태는 CIRCUIT_AUTHENTICITY.md에 기록한다. 자료 목록만으로 사진 기반 정밀 재현을 완료했다고 주장하지 않는다.
